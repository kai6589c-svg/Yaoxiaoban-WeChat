# beta.19：GitHub 参考功能交付记录

日期：2026-09-16。基线：`8206647` / beta.18。实施分支：`codex/reference-integration-beta19`。

本轮采用参考项目的产品思路，未复制其源码、未引入新的第三方 UI 或上传库。公开仓库继续默认隔离演示模式。本轮提交代码与测试；生产云函数、小程序正式版本未部署。

## 已实现

| 工作包     | 用户可见变化                                                             | 数据边界                                                                                         |
| ---------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| 照片恢复   | 表单、药箱、详情、同步页共用保存状态；本机丢图可重新选择                 | 先核对旧上传；字段确认后只修照片；新图片用新请求和票据；版本冲突停止                             |
| 7 天预览   | 固定计划表单展示后续时间与剂量，提示不完整或近期无安排                   | 复用日期、计划、效期函数；不请求通知权限、不增加保存 RPC                                         |
| 今天与历史 | 需要核对、待处理、待同步、接下来、已记录分组；历史分别显示计划与记录时间 | 未记录不等于未服；待同步记录不提供云端撤销按钮                                                   |
| 存放位置   | 可填写、选择已有位置，药箱搜索筛选，详情和导出展示                       | 可选 30 字；旧客户端漏传保留，新客户端空值清除                                                   |
| 又买一盒   | 详情快捷进入独立新盒；可折叠同款盒组                                     | 只预填成员/药名/规格/单位/位置；不复制效期、开封、照片、计划或余量；库存始终独立                 |
| 集中盘点   | 当前药箱筛选进入逐盒盘点，支持跳过、中断恢复和结束                       | 本机账号隔离；写入前持久化请求编号和盘点时间；结果未知锁定数量，重试同一请求；完成以服务端确认计 |
| 交互       | 新增位置与盘点入口、关键按钮 44px 最小触控区域、状态文案共享             | 沿用现有组件；读屏与字号放大仍需设备验收                                                         |

## 验证记录

- `npm run check`：通过，共 372 项测试（客户端 220、medicine-api 98、reminder-worker 32、maintenance-worker 18、配置 4）；构建、类型、Lint、客户端与三个云函数测试、配置/版本/索引/包体校验、格式检查、生产依赖审计。
- 行为测试包含：10 秒等待预算、图片丢失后修复、已绑定结果核对、旧票据清理与新请求、版本冲突、预览日期/星期/效期边界、新盒白名单与实际表单、位置普通/快速/旧客户端保存、盘点重启重试/账号变化/离线/空间不足/小数/版本变化。
- 构建包体 0.527 MiB，未新增第三方运行依赖；暂存变更通过 Gitleaks 扫描，未检出凭证。
- 微信开发者工具自带编译器已编译全部 15 个 WXML、16 个 WXSS 文件，退出码均为 0。这只验证模板和样式可编译，不代表页面交互通过。
- `tests/e2e/journeys.mjs` 已适配公开演示配置，新增集中盘点 → 新盒预填 → 位置录入旅程；自动化连接在本机 Nightly 启动阶段未就绪，尚未执行页面断言。可用 `E2E_APP_ID` 提供开发者工具可用 AppID，但测试运行配置始终强制本机 demo、空云环境。

## 发布前仍需完成

1. 修复或更换可正常连接的微信开发者工具环境，执行全部 E2E 并检查截图。
2. iOS / Android 普通网络、弱网、离线、后台恢复、字号放大和读屏验收。照片保存界面沿用 9,800ms 操作预算，不能据此声称所有网络云端保存都在 10 秒内成功。本轮未重新取得真实云端 P95 数据。
3. 正式配置下运行 `npm run release:check`。先部署支持位置字段的 medicine-api，再发布客户端；当前公开演示配置不能用于正式发布。
4. 单药盒暂停通知仍按原计划单独设计，未在本轮实现。低保真样稿评审、第三方组件包体比较和真实设备可用性评审未作为已完成事项。

## 回退

客户端可回退 beta.18；存放位置仍保留在云端，旧客户端编辑不会主动清除。不要删除实际盘点快照、新盒或用户待同步任务。旧客户端无法展示集中盘点进度，但本机会话应保留，恢复 beta.19 后继续核对。此版本没有修改计划计算、跨盒扣量或提醒发送策略。
